## 实现目标

本规划把“开机启动选择器、托盘设置窗口、统一设置接口、Android 管理员面板”拆成可连续交付的阶段。优先完成 Windows Agent 的配置模型、管理员鉴权和统一设置接口，再接入本机设置窗口与启动选择器，最后实现 Android 远程管理。

## 风险控制

- 任意命令行执行只允许管理员配置，所有远程修改必须通过管理员密码。
- 明文管理员密码不通过 `GET /api/settings` 返回，只允许配置文件和保存请求写入。
- 本机设置窗口和远程设置接口必须共用 `IAgentSettingsService`，避免配置行为分叉。
- 启动选择器 UI 线程独立运行，不能阻塞 ASP.NET Core Web Host。
- 启动项关闭不直接杀进程，必须调用配置的关闭脚本或程序，由关闭命令负责清理残留进程和外部依赖。
