# 开机启动选择器与手机管理员面板需求

> 创建日期: 2026-06-11 15:00
> 最后更新: 2026-06-12 22:28
> 作者: Maimai Dev
> 状态: 草稿

## 背景

maimai 家用机使用场景中，Windows 电脑可能需要在开机后直接进入接近家用游戏机的使用体验：用户无需操作 Windows 桌面，而是在一个全屏启动画面中选择要启动的程序。当前项目已经具备 Windows Agent、Android 端和 PC Web 管理能力，但还缺少面向“开机后选择启动项”的大屏入口，以及从手机端配置启动项和自启动行为的管理员能力。

## 目标

- 当 Windows Agent 配置了开机自启并随系统启动时，自动显示一个全屏启动选择画面。
- 启动画面面向竖屏显示器设计，实际逻辑分辨率为 1080x1920，主要在下半区域展示可启动项目。
- 用户可以通过启动器导航键选择启动项，并通过确认键启动当前选中项。
- Android 手机端新增管理员面板，用于配置开机自启和启动项。
- Windows Agent 托盘右键菜单新增本机设置窗口，用于配置所有配置项。
- Windows Agent 开放统一设置接口，用于手机端配合管理员密码远程管理所有配置项。
- 管理员面板需要密码验证，避免普通局域网访问者修改启动配置。

## 需求范围

### Windows 全屏启动选择器

- Windows Agent 支持一个“启动选择器”模式。
- 当开机自启配置启用，且 Windows Agent 通过系统自启动方式启动后，应自动打开全屏启动选择画面。
- 启动画面目标画布为 1080x1920，面向物理竖置显示器使用场景进行布局。
- 启动画面下半区域展示启动项列表。
- 每个启动项至少包含名称、启动命令或程序路径、关闭命令或程序路径。
- 用户选中启动项并按确认键后，系统启动该启动项配置的程序或命令。
- 启动项触发后，全屏启动选择器应最小化并保持运行。
- 启动选择器最小化后，手机端应可以对当前启动项执行关闭操作。
- 关闭启动项时，系统应调用该启动项配置的关闭命令或程序，而不是直接杀死启动进程。
- 关闭命令或程序执行完成后，启动选择器重新显示。
- 手机端管理员面板应提供重新打开启动选择器的操作入口。
- Windows Agent 应提供全局关闭快捷键，用于在启动器隐藏或其他窗口激活时关闭当前启动项并重新打开启动器。
- 启动项被触发后，应避免重复触发新的启动项。

### 启动项配置

- 支持新增、编辑、删除启动项。
- 支持配置启动项显示名称。
- 支持配置启动项对应的任意启动命令行，包括直接启动程序、传入参数和打开终端命令。
- 支持配置启动项对应的任意关闭命令行，包括调用清理脚本、关闭程序、传入参数和打开终端命令。
- 支持配置启动项工作目录。
- 支持配置启动项关闭工作目录；如果未配置，默认使用启动工作目录。
- 支持配置启动项展示顺序。
- 支持启用或禁用单个启动项。

### 开机自启配置

- 支持从手机端查看当前开机自启状态。
- 支持从手机端启用或关闭 Windows Agent 开机自启。
- 支持从手机端启用或关闭“开机后自动显示启动选择器”。
- 如果只启用了 Windows Agent 开机自启，但没有启用启动选择器自动显示，Agent 应按普通后台服务或托盘模式启动。
- 如果启动项列表为空或全部禁用，启动选择器画面应显示明确的空状态提示。

### Windows 本机设置窗口

- Windows Agent 托盘右键菜单新增“设置”入口。
- 点击“设置”后打开本机设置窗口。
- 设置窗口应包含当前 Agent 的所有可配置项，而不只包含启动选择器配置。
- 设置窗口至少支持配置管理员密码、开机自启、启动选择器自动显示、启动项列表和现有 Agent 配置项。
- 设置窗口保存后应写入 Agent 配置，并使需要即时生效的配置尽量即时生效。
- 对需要重启 Agent 才能生效的配置，设置窗口应明确提示。

### 统一设置接口

- Windows Agent 开放设置接口，用于读取和修改所有可远程管理的配置项。
- 设置接口必须要求管理员密码验证。
- 手机端管理员面板通过设置接口读取和保存配置。
- 设置接口应返回完整配置视图，便于手机端展示统一配置页面。
- 设置接口保存配置时应做服务端校验，不能只依赖手机端校验。
- 设置接口不应返回敏感配置的明文值，管理员密码等敏感项应只允许写入或显示占位状态。

### Android 管理员面板

- Android 端新增管理员面板入口。
- 管理员面板进入前需要输入管理员密码。
- 管理员密码验证通过后，当前会话内允许查看和修改管理配置。
- 管理员面板至少支持管理以下内容：开机自启状态、启动选择器自动显示状态、启动项列表和启动命令。
- 管理员面板应支持配置启动项关闭命令，并支持对当前运行启动项执行关闭操作。
- 管理员面板应通过统一设置接口管理远程配置，而不是为每类配置单独维护独立入口。
- 管理员面板保存配置后，应把配置同步到当前连接的 Windows Agent。
- 当手机未连接 Agent 时，管理员面板应显示不可配置状态，并提示先连接设备。

### 管理员密码

- Windows Agent 提供管理员密码验证能力。
- 管理员密码在 Windows Agent 配置文件中配置。
- 管理员密码允许在本机配置文件中以明文形式保存。
- 初始管理员密码为 `seganmsl`。
- 管理员密码不应以明文形式暴露给 Android 端或 PC Web 前端。
- 修改启动配置的接口必须要求通过管理员验证。
- 管理员验证失败时，Android 端应显示明确错误提示。
- 管理员密码修改通过编辑 Windows Agent 配置文件完成。

## 非目标

- 暂不实现复杂多用户权限体系。
- 暂不支持公网远程管理。
- 暂不要求 iOS 端管理员面板。
- 暂不直接控制 maimai 游戏进程内部状态。
- 暂不要求启动选择器替代 Windows 登录界面。
- 暂不要求在本需求阶段定义最终视觉设计稿。
- 暂不在启动选择器画面展示背景图、Logo、时间、网络状态等额外信息。
- 暂不要求把设置窗口做成复杂多页面配置中心，首版以可用和覆盖全部配置项为主。

## 约束

- 启动配置涉及执行本机程序或命令，必须通过管理员权限验证保护修改接口。
- 命令行、工作目录和参数需要进行基础校验，避免明显无效配置导致 Agent 异常。
- 启动项关闭应优先调用配置的关闭命令，不能默认直接结束主进程，避免清理脚本、残留进程和外部依赖未正确处理。
- 全屏启动画面不应阻塞 Windows Agent 的 HTTP/WebSocket 管理接口。
- 键盘监听应只在启动选择器画面激活时生效，避免影响普通 Windows 使用场景。
- 启动选择器画面需要适配目标 1080x1920 竖屏显示器，但后续实现应考虑实际显示器缩放和窗口全屏行为。
- 配置变更需要持久化，Windows 重启后仍然生效。
- 本机设置窗口和远程设置接口应复用同一套配置模型和校验规则，避免两端行为不一致。

## 验收标准

- Windows Agent 配置为开机自启且启用启动选择器自动显示后，系统启动 Agent 时能自动显示全屏启动选择画面。
- 启动选择器画面以 1080x1920 竖屏目标布局显示，并在下半区域展示启动项。
- 启动项列表展示名称。
- 选中某个启动项并按确认键后，对应程序或命令被启动。
- 启动程序或命令后，全屏启动选择器最小化并保持运行。
- 手机端可以对当前启动项执行关闭操作。
- 关闭当前启动项时，Windows Agent 调用配置的关闭命令或程序。
- 关闭命令或程序执行完成后，全屏启动选择器重新显示。
- 手机端管理员面板可以主动重新打开启动选择器。
- Android 管理员面板需要密码验证后才能进入或保存配置。
- Android 管理员面板可以新增、编辑、删除、启用、禁用启动项。
- Android 管理员面板可以配置启动项。
- Android 管理员面板可以查看和切换开机自启状态、启动选择器自动显示状态。
- 托盘右键菜单可以打开本机设置窗口。
- 本机设置窗口可以查看并修改所有可配置项。
- 远程设置接口可以读取和保存完整配置视图。
- 手机端管理员面板可以通过统一设置接口修改配置。
- 未通过管理员验证时，修改启动配置的接口被拒绝。
- Windows Agent 重启后，已保存的开机自启、启动选择器和启动项配置仍然保留。
