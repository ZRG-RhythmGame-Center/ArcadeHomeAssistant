# maimai 家用机辅助工具需求

> 最后更新: 2026-05-11 20:42
> 作者: Adsicmes
> 状态: 草稿

## 背景

maimai 家用机使用场景中，Windows 电脑通常承担音频输出、资源文件存放和运行环境管理。实际使用时，如果需要切换音频输出设备、调节音量或管理歌曲/资源相关文件，经常要离开手机或游戏操作位置去电脑前处理，操作不方便。

## 目标

- 通过手机 App 控制局域网内 Windows 电脑的音频输出设备。
- 通过手机 App 控制局域网内 Windows 电脑的系统音量。
- 通过手机 App 管理 Windows 电脑上多个目标文件夹的文件。
- 提供 PC 网页用于配置、管理和调试。
- 支持一台手机控制局域网内一台或多台 Windows 目标机器。

## 功能范围

### 音频控制

- 查看 Windows 当前可用音频输出设备列表。
- 查看当前默认音频输出设备。
- 切换默认音频输出设备。
- 查看和调整主音量。
- 支持静音和取消静音。
- 实时同步音量和设备状态到手机 App 和 PC 网页。

### 文件管理

- 在 Windows Agent 中配置多个可管理的目标文件夹。
- 手机 App 和 PC 网页只能访问已配置的目标文件夹。
- 浏览文件夹内容。
- 上传文件到目标文件夹。
- 下载文件。
- 删除文件。
- 重命名文件。
- 移动文件到同一目标根目录下的其他位置。

### 设备连接

- 手机 App 可发现局域网内运行中的 Windows Agent。
- PC 网页可访问本机 Windows Agent 提供的管理页面。
- 首次连接需要配对或令牌授权，避免局域网内任意设备直接控制电脑。

## 非目标

- 暂不做公网远程控制。
- 暂不做复杂用户系统。
- 暂不直接控制 maimai 游戏进程内部状态。
- 暂不做跨平台 PC Agent，优先支持 Windows。

## 约束

- Windows Agent 必须限制文件访问范围，不能开放任意磁盘路径。
- 删除、覆盖、移动等危险文件操作需要二次确认或可配置保护。
- 局域网通信需要最少的鉴权机制。
- 手机端优先考虑 Android，保留后续 iOS 可能性。

## 验收标准

- 手机 App 能发现并连接局域网内 Windows Agent。
- 手机 App 能查看音频输出设备列表并切换默认输出设备。
- 手机 App 能调整系统音量并看到状态变化。
- PC 网页能完成同样的音频控制操作。
- Windows Agent 可配置至少两个目标文件夹。
- 手机 App 和 PC 网页能浏览、上传、下载、删除、重命名已配置目标文件夹内的文件。
- 文件 API 无法越权访问未配置目录。
