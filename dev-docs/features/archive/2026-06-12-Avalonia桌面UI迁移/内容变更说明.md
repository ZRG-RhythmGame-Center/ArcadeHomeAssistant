# Avalonia 桌面 UI 迁移内容变更说明

> 创建日期: 2026-06-12 19:09
> 最后更新: 2026-06-12 19:21
> 作者: Maimai Dev
> 状态: 已完成

## 变更范围

本次变更将 Windows Agent 的本机桌面 UI 从 WinForms 迁移到 Avalonia，同时保留现有 ASP.NET Core Minimal API、统一设置服务、启动器服务和托盘入口。

## 关键文件

| 文件 | 变更说明 |
|---|---|
| `services/windows-agent/src/MaimaiHomeAgent/MaimaiHomeAgent.csproj` | 移除 WinForms 开关，新增 `Avalonia`、`Avalonia.Desktop`、`Avalonia.Themes.Fluent` 依赖。 |
| `services/windows-agent/src/MaimaiHomeAgent/Program.cs` | 注册 Avalonia UI 线程、Avalonia 设置窗口 host 和 Avalonia 启动器 host。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/Avalonia/AvaloniaUiThread.cs` | 新增独立 STA UI 线程，负责初始化 Avalonia AppBuilder 和调度 UI 操作。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/Avalonia/AvaloniaApp.cs` | 新增 Avalonia 应用入口配置，启用 Fluent 主题。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/Avalonia/Settings/AvaloniaSettingsWindowHost.cs` | 新增设置窗口宿主，实现 `ISettingsWindowHost`。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/Avalonia/Settings/SettingsWindow.cs` | 新增 Avalonia 设置窗口，以纯 C# 构建分类导航和配置表单。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/Avalonia/Settings/SettingsWindowViewModel.cs` | 新增设置窗口 ViewModel，负责加载快照、保存配置、管理启动项和文件根目录编辑状态。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/Avalonia/Launcher/AvaloniaLauncherWindowHost.cs` | 新增启动器窗口宿主，实现全屏窗口、9:16 内容区、卡片切换、确认启动和隐藏逻辑。 |
| `services/windows-agent/src/MaimaiHomeAgent/Tray/TrayApp.cs` | 托盘应用切换为使用原生 Win32 消息泵。 |
| `services/windows-agent/src/MaimaiHomeAgent/Tray/TrayImplementations.cs` | 新增 `Win32MessagePump`，使用 Win32 消息循环替代 WinForms 消息循环。 |
| `services/windows-agent/src/MaimaiHomeAgent/Ui/WinForms/*` | 删除原 WinForms 设置窗口、启动器窗口和 UI 线程实现。 |

## 行为变化

- 托盘菜单打开的设置窗口现在是 Avalonia 窗口。
- 托盘菜单打开的应用启动器现在是 Avalonia 全屏窗口。
- 启动器仍通过现有 `ILauncherService` 启动和关闭启动项，不改变启动/关闭命令语义。
- 设置保存仍通过 `IAgentSettingsService.UpdateAsync()`，不改变 HTTP API 和配置 DTO。
- 项目构建不再依赖 `UseWindowsForms`。
- 设置窗口不再显示启动项独立按键配置项，启动项通过全局导航键选择并由确认键启动。
- 设置窗口不再显示启动项“标题”配置项，启动器卡片统一使用“名称”展示。

## 注意事项

- 当前 Avalonia UI 使用 code-behind 方式构建，不依赖 XAML 文件。
- 启动器窗口逻辑当前集中在 `AvaloniaLauncherWindowHost.cs`，后续如果 UI 继续复杂化，再拆出独立 window/view model 文件。
- 托盘图标仍使用 `H.NotifyIcon`，只是消息循环不再走 WinForms。
