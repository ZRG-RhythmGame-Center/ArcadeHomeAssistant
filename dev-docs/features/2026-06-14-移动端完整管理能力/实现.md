## 目标

本轮实现交付 Android 移动端的完整 Agent 管理能力，对应原始规划的阶段 8、9、10。分为数据层、UI 层、联调三个大阶段，每阶段内部细分为可独立提交的步骤。

## 前置条件

- Agent 侧阶段 1-7 已全部完成
- Agent 暴露的管理接口：`POST /api/admin/session`、`GET/PUT /api/settings`、`GET /api/launcher/status`、`POST /api/launcher/show`、`POST /api/launcher/start`、`POST /api/launcher/stop`
- 密码通过 `Authorization: Bearer {password}` 头传递

### 1.2 AgentClient 新增管理方法

文件: `app/src/main/kotlin/com/maimai/home/data/AgentClient.kt`

- [ ] `verifyAdminPassword(address, password)` — POST `/api/admin/session`，成功返回 true
- [ ] `fetchSettings(address, password)` — GET `/api/settings`，带 Bearer 头
- [ ] `updateSettings(address, password, request)` — PUT `/api/settings`，带 Bearer 头
- [ ] `fetchLauncherStatus(address, password)` — GET `/api/launcher/status`
- [ ] `showLauncher(address, password)` — POST `/api/launcher/show`
- [ ] `startLauncherItem(address, password, itemId)` — POST `/api/launcher/start`
- [ ] `stopLauncherItem(address, password)` — POST `/api/launcher/stop`

所有管理方法接收 `password: String` 参数，构造 `Authorization: Bearer $password` 请求头。401 响应抛出包含"管理员密码错误"的 `AgentRequestException`。

## Phase 2: UI 层 — 管理员面板

目标：实现完整的管理员 UI，用户可以通过手机管理 Agent。

### 2.1 AdminViewModel

文件: `app/src/main/kotlin/com/maimai/home/ui/admin/AdminViewModel.kt`

- [ ] 定义 `AdminUiState`：

```kotlin
data class AdminUiState(
    val address: String,
    val machineName: String,
    // 登录状态
    val password: String = "",
    val isAuthenticated: Boolean = false,
    val isAuthenticating: Boolean = false,
    // 设置
    val settings: AgentSettingsSnapshot? = null,
    val isLoadingSettings: Boolean = false,
    // 启动器
    val launcherStatus: LauncherStatus? = null,
    val isLauncherActionPending: Boolean = false,
    // 编辑状态
    val editedSettings: AgentSettingsUpdateRequest? = null,
    val isSaving: Boolean = false,
    val saveSuccess: Boolean = false,
    // 错误
    val errorMessage: String? = null,
)
```

- [ ] 实现方法：
  - `login()` — 调用 `verifyAdminPassword`，成功后设置 `isAuthenticated` 并加载设置
  - `loadSettings()` — 拉取 `/api/settings` 和 `/api/launcher/status`
  - `saveSettings(request)` — 调用 `updateSettings`，成功后重新加载
  - `showLauncher()` — 调用 `showLauncher`
  - `startItem(itemId)` — 调用 `startLauncherItem`
  - `stopItem()` — 调用 `stopLauncherItem`
  - `refreshLauncherStatus()` — 刷新启动器状态
  - `logout()` — 清除密码和认证状态

- [ ] 订阅 EventStream，监听 `launcher.*` 和 `settings.updated` 事件刷新状态
