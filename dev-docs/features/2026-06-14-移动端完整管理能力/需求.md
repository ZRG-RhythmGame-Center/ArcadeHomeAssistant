# 移动端完整管理能力

> 创建日期: 2026-06-14 00:44
> 最后更新: 2026-06-14 00:44
> 作者: Maimai Dev
> 状态: 已确认

## 背景

Android 移动端目前已实现音频控制、文件管理、远程关机和设备连接功能。但 Agent 侧在 2026-06-11 完成了管理员鉴权、统一设置接口（`/api/settings`）和启动选择器管理接口（`/api/launcher/*`），移动端尚未接入。用户无法通过手机完整管理 PC 端的所有配置和启动器行为。

## 目标

让 Android 手机端具备完整管理 PC Agent 的能力，所有需要管理员权限的操作通过密码验证保护。

## 用户故事

作为街机管理员，我希望通过手机远程管理 PC Agent 的全部配置和启动器，以便不需要走到 PC 前即可完成日常运维。

## 功能描述

### 核心功能

- [x] Agent 侧管理员鉴权已就绪（`POST /api/admin/session`）
- [x] Agent 侧统一设置接口已就绪（`GET /PUT /api/settings`）
- [x] Agent 侧启动器管理接口已就绪（`/api/launcher/*`）
- [ ] 移动端管理员登录：输入密码，验证成功后本次会话保持凭证
- [ ] 移动端查看和修改 Agent 全局设置
- [ ] 移动端管理启动项列表（新增、编辑、删除、启用/禁用、排序）
- [ ] 移动端控制启动器（查看状态、重新显示、启动指定项、关闭当前项）
- [ ] 移动端修改管理员密码

### 管理员入口位置

在底部导航栏新增"管理"Tab（或在现有"设备"页内添加管理员入口），满足以下约束：

- 未连接 Agent 时显示不可操作状态
- 未验证密码时仅显示密码输入表单
- 验证成功后展示完整管理面板

### 管理面板包含的配置项

1. 开机自启（AutoStartEnabled）
2. 启动器自动显示（ShowOnAgentStart）
3. 显示延迟秒数（ShowDelaySeconds）
4. 画布尺寸（CanvasWidth / CanvasHeight）
5. 启动器壁纸路径（BackgroundImagePath）
6. 全局导航键（NavigateLeftKey / NavigateRightKey / ConfirmKey / StopKey）
7. 启动项列表管理
8. 远程关机配置（Enabled / ControlToken）
9. 文件根目录管理
10. 管理员密码修改

### 启动器控制面板

1. 当前状态展示（是否显示、当前运行项、最近错误）
2. "重新显示启动器"按钮
3. "启动指定项"快捷按钮（根据启动项列表生成）
4. "关闭当前项"按钮

### 边界条件

- 管理员密码错误 → 提示"密码错误"，不清空输入
- Agent 离线 → 管理面板显示"未连接"，禁用所有操作
- 保存设置返回校验错误 → 显示服务端错误消息
- 启动器操作返回冲突状态 → 显示对应提示（如"已有启动项运行中"）
- 密码修改成功 → 使用新密码重新验证

## 非功能需求

- 性能: 设置加载和保存响应时间 < 2 秒（局域网环境）
- 兼容性: Android 8.0+ (API 26+)，与现有 app 保持一致
- 安全性: 管理员密码通过 `Authorization: Bearer {password}` 传输，仅限局域网通信（已有 `LanAddressPolicy` 限制）；密码不持久化到本地存储，每次启动 app 需重新验证

## 验收标准

1. 手机端输入正确密码可进入管理面板
2. 手机端可查看所有设置项，修改后保存生效（PC 端同步更新）
3. 手机端可新增/编辑/删除启动项，保存后启动器配置更新
4. 手机端可重新显示启动器窗口
5. 手机端可启动和关闭指定启动项
6. 错误密码、网络断开、服务端校验失败均有明确 UI 反馈
7. 所有管理操作不影响现有音频/文件/电源功能

## 优先级与排期

- 优先级: P0
- 预计工期: 3-4 个开发会话
- 依赖项: Agent 侧阶段 1-7 已完成（管理员鉴权、统一设置接口、启动器管理 API）
