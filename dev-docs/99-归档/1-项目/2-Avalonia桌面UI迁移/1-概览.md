# Avalonia 桌面 UI 迁移概览（已归档）

## 目标

将 Windows Agent 的本机桌面 UI 从 WinForms 迁移到 Avalonia，保留现有 ASP.NET Core Minimal API、统一设置服务、启动器服务和托盘入口。

## 状态

已实现并归档。Windows Agent 已移除 WinForms 依赖，设置窗口和启动器迁移到 Avalonia，托盘消息循环改为原生 Win32。
