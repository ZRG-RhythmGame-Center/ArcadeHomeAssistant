# 移动端完整管理能力概览

## 目标

让 Android 手机端具备完整管理 PC Agent 的能力：接入统一设置接口（`/api/settings`）和启动选择器管理接口（`/api/launcher/*`），修复上传与实时事件链路缺陷，并移除历史鉴权实现（管理员密码、控制令牌）。产品只在可信局域网内使用，不设置登录、密码、控制令牌、API Key 或配对流程。

## 状态

规划中：产品需求已确认，技术设计已采纳，实现计划已规划。2026-07-16 项目准则确定 LAN 内所有功能免凭据，原管理员认证相关方案已废止，执行顺序以功能缺口调研为准。2026-07-28 按源码盘点补充端点/事件/Capabilities 缺口总表，并将实现计划正文与免凭据准则对齐（新增 Phase 0 Agent 侧改造，移除登录/密码/控制令牌任务）。
