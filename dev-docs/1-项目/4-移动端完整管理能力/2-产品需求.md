# 移动端完整管理能力

## 背景

Android 移动端目前已实现音频控制、文件管理、远程关机和设备连接功能。但 Agent 侧的统一设置接口（`/api/settings`）和启动选择器管理接口（`/api/launcher/*`）尚未被移动端接入，上传与实时事件链路也存在可用性缺陷。Agent 现有管理员密码和关机控制令牌是待移除的历史实现。

## 目标

让 Android 手机端具备完整管理 PC Agent 的能力。产品只在可信局域网内使用，连接 Agent 后直接使用全部能力，不设置登录、密码、控制令牌、API Key 或配对流程。

## 用户故事

作为街机管理员，我希望通过手机远程管理 PC Agent 的全部配置和启动器，以便不需要走到 PC 前即可完成日常运维。

## 功能描述

### 核心功能

- [x] Agent 侧统一设置接口已就绪（`GET /PUT /api/settings`）
- [x] Agent 侧启动器管理接口已就绪（`/api/launcher/*`）
- [ ] 移除 Agent 设置、启动器和远程关机接口的历史鉴权，删除 `POST /api/admin/session` 路由及 `Admin.Password` 配置块
- [ ] 移除移动端控制令牌输入和所有凭据相关状态
- [ ] 移动端查看和修改 Agent 全局设置
- [ ] 移动端管理启动项列表（新增、编辑、删除、启用/禁用、排序）
- [ ] 移动端控制启动器（查看状态、重新显示、启动指定项、关闭当前项）
- [ ] 修复文件上传目标路径和 WebSocket 心跳

### 管理入口位置

在底部导航栏新增“管理”Tab（或在现有“设备”页内添加管理入口），满足以下约束：

- 未连接 Agent 时显示不可操作状态
- 连接 Agent 后直接展示完整管理面板
- Agent 未声明对应 capability 时隐藏或禁用相关分区

### 管理面板包含的配置项

1. 开机自启（AutoStartEnabled）
2. 启动器自动显示（ShowOnAgentStart）
3. 显示延迟秒数（ShowDelaySeconds）
4. 画布尺寸（CanvasWidth / CanvasHeight）
5. 启动器壁纸路径（BackgroundImagePath）
6. 全局导航键（NavigateLeftKey / NavigateRightKey / ConfirmKey / StopKey）
7. 启动项列表管理
8. 远程关机配置（Enabled）
9. 文件根目录管理

### 启动器控制面板

1. 当前状态展示（是否显示、当前运行项、最近错误）
2. "重新显示启动器"按钮
3. "启动指定项"快捷按钮（根据启动项列表生成）
4. "关闭当前项"按钮

### 边界条件

- Agent 离线 → 管理面板显示"未连接"，禁用所有操作
- 保存设置返回校验错误 → 显示服务端错误消息
- 启动器操作返回冲突状态 → 显示对应提示（如"已有启动项运行中"）
- 关机、删除等破坏性操作 → 必须明确二次确认

## 非功能需求

- 性能: 设置加载和保存响应时间 < 2 秒（局域网环境）
- 兼容性: Android 8.0+ (API 26+)，与现有 app 保持一致
- 信任边界: 仅允许连接局域网地址，沿用现有 `LanAddressPolicy` 和 `LanDns`；不引入任何访问凭据
- 正确性保护: 保留路径边界、只读根目录、输入校验和破坏性操作二次确认

## 验收标准

1. 手机端连接 Agent 后无需登录或输入凭据即可进入管理面板
2. 手机端可查看所有目标设置项，修改后保存生效（PC 端同步更新）
3. 手机端可新增/编辑/删除启动项，保存后启动器配置更新
4. 手机端可重新显示启动器窗口
5. 手机端可启动和关闭指定启动项
6. 网络断开、服务端校验失败和状态冲突均有明确 UI 反馈
7. 远程关机无需令牌，但必须经过二次确认
8. 文件上传和 WebSocket 心跳通过对应验收测试
9. 所有管理操作不影响现有音频/文件/电源功能

## 优先级与排期

- 优先级: P0
- 预计工期: 3-4 个开发会话
- 依赖项: Agent 统一设置和启动器管理 API 已完成；接入前需先移除历史鉴权
