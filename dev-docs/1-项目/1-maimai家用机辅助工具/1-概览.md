# maimai 家用机辅助工具概览

## 目标

通过手机 App 和 PC 网页在局域网内控制 Windows 电脑的音频输出、系统音量、文件管理，并提供 PC 网页用于配置、管理和调试。

## 状态

进行中：Windows Agent（C# + ASP.NET Core）、PC Web（React + Vite）、Android 移动端（Kotlin + Jetpack Compose）三端 MVP 已落地，持续扩展管理能力。
