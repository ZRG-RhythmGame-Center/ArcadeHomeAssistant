# 全仓审查问题修复 — 唯一索引与阶段状态契约

本文件是本项目唯一导航入口、阶段状态来源和阻断清单。`4-技术设计.md` 是唯一技术权威，`3-验收标准.md` 是唯一 AC 入口；计划、测试、UX、台账和迁移计划不得另立技术方案或将方案写成已实施、已验收或可发布。

## 目标结果

在不扩大安全范围的前提下，落实 PC Web 同源导航、Android 五项底栏与管理二级 Power、Agent settings 条件写/统一仓储/事件 v2、cursor v2 与 v1 兼容。历史 Android UI 仅建台账并复验，不整体重开。

## 范围

本项目覆盖相关 PC Web、Android、Windows Agent、Avalonia/托盘的设计、测试编排、兼容迁移、回滚和文档治理。认证、凭据、CORS、LAN 策略、数据库、消息队列和产品代码改动不在本次文档任务范围内。

## 决策

| ID | 已批准决定 | 影响 |
|---|---|---|
| ADR-01 | PC Web 使用页面 origin 的相对 API/WS；切换 Agent 整页导航至目标 origin。 | 不发跨 origin XHR/WS；cache 以 targetKey 隔离。 |
| ADR-03 | Android 底栏固定五项；Admin 风险操作进入二级 Power，返回 Admin。 | P0；禁止第六个 Power Tab。 |
| ADR-04/07 | revision/ETag/If-Match 与唯一 settings repository。 | 条件写、恢复日志、补偿和部分失败分类。 |
| ADR-08/10 | event envelope v2 加性发布，以 capability 与 HTTP 对账兼容迁移。 | WebSocket 不作为状态日志。 |
| ADR-09 | cursor v2 严格全序、opaque token、目录变更中断；v1 保持兼容。 | 仅稳定目录链保证无重漏。 |
| HUI | 历史 Android UI 只建台账和复验。 | 仅复验失败单项可另行立项。 |
