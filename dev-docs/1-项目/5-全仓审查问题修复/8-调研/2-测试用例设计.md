# 全仓审查问题修复 — 测试用例设计

## 阅读与执行规则

`P0` 是发布阻断项。每例按 Given–When–Then 执行并保存所列证据；未具备 capability 的条件用例标为“不适用”，不是通过。失败按本文件最短步骤建 BUG 并退回实现者，不降低断言、不改生产逻辑。关联编号仅使用本项目需求 `REQ-01`～`REQ-12`、[验收标准](../3-验收标准.md)的 `AC-01`～`AC-11` 和测试策略风险 ID；不引用派生 `REQ-WEB-*`、`REQ-AND-*`、`REQ-AGENT-*`、不存在的 REQ-13 或 AC-12/13。

|---|---|---|---|---|

## F. Avalonia 与缺口登记

AVA-01～AVA-07 保留为 P1/P2 回归：空/单/多项边界、点击/键盘单次回调、三分辨率布局、焦点保护取消，以及交互式 Windows VM 托盘反馈。自动化不能替代 AVA-06/07 的桌面录像。

|---|---:|---|
| GAP-01 | P0 | SharedEventStream 必须提供可订阅的 reconnect/gap/instance 对账信号及单次责任；AND-03～05 可观察并通过后关闭 |
