## Mechanism
Source: services/windows-agent/src/MaimaiHomeAgent/Security/JsonFileTokenStore.cs

  1. Serialize tokens to <path>.tmp via FileStream(FileMode.Create, FileShare.None) then FlushAsync
  2. File.Move(tmp, target, overwrite: true) -- NTFS uses MoveFileEx REPLACE_EXISTING (atomic)
  3. Reads open with FileShare.Read; writes open with FileShare.None
  4. SemaphoreSlim(1,1) gates all ops -> single-writer, serialized reads
  5. Directory auto-created on first write if missing
  6. JsonException / IOException / UnauthorizedAccessException on read => log warning + empty list (do not crash agent on corrupt store)
  7. MVP: tokens stored in plaintext (per task spec); SHA-256 hashing deferred. Note in TokenRecord XML doc.

## Source extract (WriteAllAsync)

    private async Task WriteAllAsync(IReadOnlyList<TokenRecord> tokens)
    {
        var dir = Path.GetDirectoryName(_filePath);
        if (!string.IsNullOrEmpty(dir) && !Directory.Exists(dir))
        {
            Directory.CreateDirectory(dir);
        }

        // 1) Write to .tmp
        await using (var fs = new FileStream(
            _tempFilePath, FileMode.Create, FileAccess.Write, FileShare.None))
        {
            await JsonSerializer.SerializeAsync(fs, tokens, JsonOptions).ConfigureAwait(false);
            await fs.FlushAsync().ConfigureAwait(false);
        }

        // 2) Atomic replace. File.Move(..., overwrite:true) maps to MoveFileEx REPLACE_EXISTING on NTFS.
        File.Move(_tempFilePath, _filePath, overwrite: true);
    }

## Key proofs

- AtomicWrite_DoesNotLeaveTempFile
    After AddAsync, asserts tokens.json.tmp does NOT exist on disk.
    Proves: File.Move successfully consumes the temp file (no leak).

- Concurrent_50_Adds_AllReadableBack
    Fires 50 parallel AddAsync via Task.Run; on completion ListAsync returns 50 distinct ids.
    Proves: SemaphoreSlim(1,1) serializes the read-modify-write cycle, no records lost.
    A naive WriteAllText without the gate would lose writes here (last-writer-wins on stale read).

- Add_Persists_AcrossInstances
    First store writes one record then disposes; second store reads it back.
    Proves: on-disk JSON is well-formed and round-trippable.

- ReadFailure_FallsBackToEmpty
    Pre-seeds tokens.json with malformed JSON; ListAsync returns empty list,
    then a subsequent AddAsync overwrites the file atomically.
    Proves: corrupt store does not brick the agent.
