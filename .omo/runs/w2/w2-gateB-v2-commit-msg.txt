Fix:
- Asserting the post-reset state IMMEDIATELY after rule.afterEach(ctx),
  with NO intervening setMain. The probe is
  Dispatchers.Main.isDispatchNeeded(EmptyCoroutineContext), which kotlinx-
  coroutines-test 1.10+ throws IllegalStateException for whenever the test
  override has been popped and no platform Main is available (JVM unit
  tests). assertFailsWith<IllegalStateException> catches that and a
  defensive defensive contains-check on the message ensures the failure
  truly references Dispatchers.Main / resetMain rather than some leaked
  generic ISE.
- Why isDispatchNeeded() instead of runBlocking { withContext(Main) {...} }:
  the latter can deadlock instead of throwing because the missing dispatcher
  swallows the continuation rather than dispatching it (the runBlocking just
  parks waiting for a wakeup that never arrives). isDispatchNeeded() is
  synchronous, has no continuation machinery, and throws immediately.
